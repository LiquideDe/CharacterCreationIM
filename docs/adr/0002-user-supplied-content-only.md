# ADR-0002: Content pack правил поставляется с клиентом и импортируется локально

Date: 2026-10-27

## Контекст

Для игры нужны структурированные карточки правил — например, названия и короткие описания талантов. Планируется использовать неофициальный перевод, при этом официальной русской версии нет.

## Решение

Приложение реализует нейтральный content-pack format и локальный импорт пользователем. Существующие JSON с карточками талантов, психосил и иных правил поставляются вместе с клиентом. Дополнительные пользовательские пакеты также могут импортироваться локально.

## Последствия

- Поставляемый rule content является частью релиза и требует учёта в релизной документации.
- Отсутствие официального перевода само по себе не подтверждает разрешение на распространение; до публичного релиза владельцы проекта отдельно проверяют правовой статус и принимают решение о публикации.
- Формат остаётся независимым от конкретной игры, поэтому в будущем можно импортировать и другие rules/content packs.
