# ADR-0001: Лицензия исходного кода — MIT

Date: 2026-10-27

## Контекст

Проект планируется распространять бесплатно и с открытым исходным кодом. Нужна короткая, понятная и совместимая с большинством Unity-пакетов лицензия.

## Решение

Использовать MIT License для собственного исходного кода. Корневой `LICENSE` уже содержит полный текст MIT и copyright `LiquideDe, 2025`.

Сторонние пакеты не перелицензируются: для каждого сохраняются его исходные license/notice. Перед релизом добавляется `NOTICE` с перечнем зависимостей и их лицензий.

## Последствия

- Другие люди могут использовать, менять и распространять наш код при сохранении copyright notice и текста MIT.
- MIT не даёт прав на Imperium Maledictum, перевод книги, чужую музыку, изображения или товарные знаки.
- Изменять имя правообладателя в существующем `LICENSE` можно только по явному решению владельца прав.
