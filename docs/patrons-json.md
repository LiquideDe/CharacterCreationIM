# Справочники покровителей

Исходные данные лежат в `Assets/StreamingAssets/Покровитель/`. В каждом из пяти файлов корень имеет вид `{ "data": [ ... ] }`. Файлы должны быть строгим JSON: двойные кавычки, без комментариев и запятой после последнего элемента. Сохранённые покровители создаются отдельно в `Assets/StreamingAssets/Покровители/<имя>/<имя>.json`; эти файлы не редактируют как справочник.

## Что сообщить для новой записи

Можно прислать мне три пункта:

1. **Название** — точное имя записи и тип: служба/должность, возможность, слабость, стремление или характер.
2. **Описание** — текст для игрока, который появится в мастере.
3. **Что делает** — правило, в том числе числовые значения и список специализаций или служб, если эффект должен применяться автоматически. Для решения ведущего прямо укажите «нарративно, без автоматического эффекта».

Для новой должности также нужны служба, обязательная возможность, базовое влияние и разрешённые списки возможностей/слабостей. Для скидки нужны точные названия специализаций и размер скидки в ОО. Для штрафа влияния нужны точные названия служб и числа со знаком, например `-2`.

Если у возможности есть вложенный выбор, пришлите название и описание каждого варианта и укажите, разрешён ли повторный выбор самой возможности с новым вариантом. Поле `repeatable` управляет выбором нескольких разных вариантов.

## Поля файлов

| Файл | Поля записи | Как используется |
|---|---|---|
| `Покровители.json` | `faction`, `responsibilities`, `description`, `opportunity`, `description_oppotrunity`, `possibilities`, `weakness`, `influence` | Одна запись задаёт должность внутри службы. `opportunity` обязательна; `possibilities` содержит рекомендуемые возможности должности, `weakness` — доступные ей слабости. `influence` — словарь «служба: число». Написание `description_oppotrunity` сохранено как в текущем формате. |
| `Возможности.json` | `name`, `description`, `additional_influence`, `influence_bonus`, `specialization_sale`, `amount_sale`, `psy_sale`, `variants`, `repeatable` | `name` и `description` показываются в мастере. `influence_bonus` — словарь «служба: числовой бонус», который добавляется к влиянию покровителя. Если заданы `specialization_sale` и `amount_sale`, указанная сумма ОО вычитается из цены этих специализаций. Если задан `psy_sale`, указанная сумма ОО вычитается из цены покупки психосил (малых и обычных). `variants` задаёт вложенные варианты с `name` и `description`; `repeatable: true` позволяет отметить несколько разных вариантов. `additional_influence` содержит имя службы без числа и само по себе не меняет влияние. |
| `Слабости.json` | `name`, `description`, `penalty_influence`, `penalty_amount`, `specialization_sale` | Пары элементов `penalty_influence[i]` и `penalty_amount[i]` меняют влияние соответствующей службы. Пустые списки означают отсутствие автоматического эффекта. `specialization_sale` в текущих данных пуст и не используется для цены. |
| `Стремления.json` | `name`, `description` | Выбор и показ текста. Пустая первая запись не предлагается игроку. |
| `Характер.json` | `name`, `description` | Выбор и показ текста. |

Для нарративной возможности или слабости достаточно `name`, `description` и пустых массивов эффектов соответствующего вида. Не извлекайте число из текста описания: автоматическое правило должно быть задано отдельными числовыми полями. Если новое правило требует нового поля, нужно дополнить `PatronOption`/`PatronTemplate`, загрузку, отображение и сервис `PatronEffects`, затем проверить сохранение и экран развития.

Все записи `Возможности.json` доступны любому покровителю. В мастере сначала показаны рекомендованные возможности его должности, затем остальные общие возможности; для длинного списка есть поиск. Слабости по-прежнему берутся из списка должности.

### Пример скидки

```json
{
  "name": "База подготовки пустоходов",
  "description": "Цена перечисленных специализаций падает на 20 ОО.",
  "additional_influence": "Навис Империалис",
  "specialization_sale": ["Зрение", "Пилотирование"],
  "amount_sale": 20
}
```

Скидки от **разных** возможностей складываются. Если обязательная и выбранная возможность совпадают по имени, запись учитывается один раз. Итоговая цена не бывает ниже нуля. Скидки не распространяются на навыки и таланты.

### Бонус влияния

```json
{
  "name": "Связи с Адептус Арбитрес",
  "description": "Описание связи с арбитрами и её применения в кампании.",
  "additional_influence": "Адептус Администратум",
  "influence_bonus": {"Адептус Администратум": 1},
  "specialization_sale": []
}
```

`influence_bonus` учитывается при расчёте влияния выбранной и обязательной возможности; одинаковая запись не применяется дважды. Условные последствия применения арбитров — секретность 4 и потеря очка превосходства — остаются в описании для ведущего, так как возникают только после использования сил в кампании.

«Светоч правосудия» уже добавлен в `Возможности.json`. Его удвоение влияния на Инквизицию действует только в социальных проверках при применении «Безграничной власти». В приложении нет расчёта таких проверок, поэтому базовое и сохранённое влияние покровителя эта возможность не меняет; ограничение секретности также хранится в описании.

«Связи с орденом космодесанта» добавлены как общая нарративная возможность: один вызов Астартес за кампанию, число бойцов определяет орден; последствия для секретности и превосходства применяет ведущий после вызова. Это отдельная запись от «Флотского десанта», который предоставляет бойцов Навис Империалис один раз за задание.

«Щит от демонов» добавлен отдельно от «Обрядов очищения»: он даёт выбираемое преимущество в одной подходящей проверке за задание, включая встречную проверку против псайкера или демона. Приложение не проводит такие проверки, поэтому использование отмечает игрок или ведущий.

«Агенты в культе смерти» добавлены отдельно от «Агентурной сети» и «Банды»: один убийца пытается устранить одну цель раз за задание, действиями убийцы управляет ведущий.

«Связи с Оффицио Ассасинорум» добавлены отдельно от «Агентов в культе смерти»: раз за кампанию Оффицио устраняет одну цель и само определяет подходящего ассасина. Бонус +1 к Адептус Администратум учитывается автоматически; снижение секретности на 1–3 очка и последствия злоупотребления определяет ведущий.

«Помощь Караула Смерти» добавлена отдельно от «Связей с орденом космодесанта»: она касается именно истребительной команды Караула Смерти и требует доказанной угрозы ксеносов. Возможное наказание за ложный вызов не имеет числа и остаётся на решение ведущего.

«Помощь Серых Рыцарей» добавлена отдельно от «Помощи Караула Смерти» и «Связей с орденом космодесанта»: она касается демонической угрозы и требует серьёзного риска прорыва Варпа или доказательств вмешательства демонов. Возможная потеря влияния в Ордо Маллеус за злоупотребление не имеет заданного числа и остаётся на решение ведущего.

«Охотничьи псы» позволяют выдать группе кибермастифа или другого фамильяра до конца задания; им управляет игрок, а подробности применения определяет ведущий. Указанная в описании скидка вдвое на содержание фамильяра не автоматизирована, поскольку в приложении пока нет расчёта этой стоимости.

«Оружейник-джокаэро» перед каждым заданием улучшает случайный предмет снаряжения: ведущий определяет предмет и достоинство броском по указанным в описании таблицам. Приложение не хранит характеристики предметов и их достоинства, поэтому эффект остаётся нарративным.

«Связи с Ордо Темпестус» добавлены отдельно от «Связей с орденом космодесанта»: батальон отпрысков Темпестус выделяется один раз за кампанию. Бонус +1 к Астра Милитарум учитывается автоматически через `influence_bonus`; падение секретности до 4 и потеря очка превосходства остаются на решение ведущего.

«Пелена в Варпе» — нарративная возможность: потеря единицы решимости у противостоящих псайкеров применяется ведущим во время партии, в приложении таких расчётов нет.

«Наставление для псайкеров» снижает затраты опыта на приобретение дополнительных психосил на 20 очков. Скидка автоматизирована полем `psy_sale`: `PatronEffects.PsyPowerDiscount` суммирует его по обязательной и выбранной возможности, а `UpgradePsyPresenter` вычитает из цены покупки (итог не ниже нуля). По тексту правила скидка действует «между заданиями», но в приложении она применяется при любой покупке психосилы у покровителя с этой возможностью — как и скидки на специализации.

«Сомнительные союзники» добавлены отдельно от «Тайного союзника»: возможность описывает доступ к сомнительным слугам, наёмникам и контактам покровителя без автоматически рассчитываемого числового эффекта.

### Возможность с вариантами

```json
{
  "name": "Оружие чужаков",
  "description": "Общее описание возможности и правило выбора типа.",
  "additional_influence": "",
  "specialization_sale": [],
  "repeatable": true,
  "variants": [
    {"name": "Альдарское", "description": "Снаряжение, доступное в начале задания."},
    {"name": "Т’ау", "description": "Снаряжение, доступное в начале задания."}
  ]
}
```

Для такой возможности мастер открывает отдельный шаг после выбора возможности и слабости. Без `repeatable` можно выбрать один вариант; при `repeatable: true` — несколько разных вариантов, каждый не более одного раза. Выбранные названия сохраняются в `PossibilityVariants` покровителя и показываются при назначении персонажу. Само снаряжение остаётся нарративным правилом: автоматическая выдача предметов не задана этими полями. У старых сохранённых покровителей, где поля нет, список считается пустым.

### Пример штрафа влияния

```json
{
  "name": "Трус",
  "description": "Описание для игрока.",
  "penalty_influence": ["Астра Милитарум"],
  "penalty_amount": [-2],
  "specialization_sale": []
}
```

## Ссылки, которые нужно дополнить

Ордо Еретикус, Ордо Ксенос и Ордо Маллеус теперь имеют по две должности: «Пуританин» и «Радикал». Новые шаблоны получили прежние описания соответствующего ордо, обязательную возможность «Безграничная власть» и влияние `Инквизиция: 2`; отдельные описания и значения можно задать позднее.

В `Возможности.json` пока отсутствуют: «Помощь Сороритас», «Пси-подготовка».

В `Слабости.json` пока отсутствуют: «В помощи отказано», «Враг на охоте», «Игра интриг», «Идея-фикс», «Контакт с еретехами», «Кризис веры», «Опасные задания», «Пропащий и проклятый», «Слепой агент», «Тайные убеждения».

Пока записи не заполнены, эти названия отображаются в мастере как недоступные. `Служебная возможность: Нуль-санктум` имеет описание в шаблоне другой должности, но отдельной записи в `Возможности.json` нет; она остаётся нарративной до добавления записи с явным эффектом.

В новых списках названия из запроса приведены к существующим записям: «Тайный тренировочный лагерь Инквизиции» → «Тайный тренировочный лагерь», «Агент. сеть» → «Агентурная сеть», «Санктум Обскурус» → «Санктум обскурус», «Стратегос Экстремис» → «Стратегос экстремис», «Ксенотехник» → «Ксенотех». Это позволяет мастеру находить описания и уже заданные эффекты.

Сейчас пересекаются специализации: «Семинария» + «Школа Администратума» — «Высокий готический»; «Тайный тренировочный лагерь» + «Школа Администратума» — «Следствие», «Сбор сведений»; «База подготовки пустоходов» + «Тайный тренировочный лагерь» — «Зрение»; «База подготовки пустоходов» + «Военная академия» — «Страх».
