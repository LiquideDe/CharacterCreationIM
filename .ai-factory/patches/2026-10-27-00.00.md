# FishNet scene token was not serialized after adding NetworkBehaviour

**Date:** 2026-10-27 00:00
**Files:** `Assets/Scenes/OnlineScene.unity`, `Assets/_project/Runtime/Networking/NetworkSandboxToken.cs`
**Severity:** medium

## Problem

The sandbox token disappeared when play mode started, despite having a `NetworkObject` and a configured observer condition.

## Root Cause

The saved `NetworkObject` initially stored an empty `NetworkBehaviours` list, which required reserialization. After reserialization, the remaining visibility failure was caused by the default `SceneCondition`: it only observes a client when FishNet has recorded the client in the object's scene. `OnlineScene` is loaded locally before connecting, so the condition evaluates to false and FishNet hides the host renderers.

## Solution

Reserialize the scene NetworkObject with FishNet's editor utility. For the sandbox token, add a `NetworkObserver` with `Override Type = Ignore Manager` and no conditions, so it is visible to every connected client. Added lifecycle logs to verify that FishNet initializes it on both host and client.

## Prevention

After adding or removing a `NetworkBehaviour` on a scene `NetworkObject`, run FishNet's **Reserialize NetworkObjects** utility before testing. Do not use `SceneCondition` for locally loaded sandbox scenes; reserve it for maps loaded through FishNet's scene-management flow.
