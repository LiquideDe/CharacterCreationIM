# Исправление требований талантов

**Date:** 2026-10-18 00:00
**Files:** Assets/_project/Scripts/Creators/TalentCreator.cs, Assets/_project/Scripts/Presenters/TalentUpgradePresenter.cs, Assets/_project/Scripts/View/TalentUpgrade/TalentUpgradeView.cs, Assets/StreamingAssets/Таланты/Псайкер.json
**Severity:** high

## Problem

Таланты с требованием уровня навыка были недоступны даже при достаточной прокачке навыка. Талант «Псайкер» был доступен персонажам без этого таланта при развитии.

## Root Cause

Обработчик `skill_improvement` передавал в поиск навыка поле `specialization`, тогда как JSON хранит название навыка в `skill`. Для таланта «Псайкер» в данных не было условия, различающего создание и последующее развитие персонажа.

## Solution

Проверка навыка теперь использует `requirement.skill`. Добавлен декларативный тип требования `development_requirement_talent`: при развитии талант «Псайкер» требует уже имеющийся талант «Псайкер», но при создании персонажа проверка не применяется. В интерфейсе выводится это требование, а проверка пишет диагностическую строку с префиксом `[FIX:TalentRequirements]`.

## Prevention

- Использовать одноимённые поля требований при сопоставлении с данными персонажа.
- Для ограничений контента описывать правило в JSON и учитывать контекст создания либо развития персонажа.
- Добавить тесты для навыков с достаточным и недостаточным уровнем, а также для требования роли.
