# CharacterCreationIM

## Назначение

Неофициальное настольное приложение для создания, редактирования, развития и печати персонажей Imperium Maledictum. Игровые справочники хранятся в JSON внутри `Assets/StreamingAssets`; созданные персонажи сохраняются там же, в каталоге `Персонажи`.

## Существующие возможности

- Создание персонажа с выбором происхождения, службы, роли, внешности, целей и снаряжения.
- Редактирование и развитие сохранённого персонажа.
- Экспорт листов персонажа в изображения.
- Загрузка игровых данных из JSON при запуске приложения.

Кнопка создания покровителя и справочники в `Assets/StreamingAssets/Покровитель` уже есть, но обработчик кнопки пуст, поэтому отдельная система покровителей пока не работает.

## Технологии

- Unity `6000.0.60f1`, C# и Unity UI/TextMesh Pro.
- Zenject для регистрации зависимостей и создания объектов.
- R3 и ObservableCollections для событий и изменяемого состояния.
- UniTask для асинхронной загрузки; Newtonsoft.Json и `JsonUtility` для JSON.
- Файловое хранение; отдельной базы данных и ORM нет.

## Организация

Основной код находится в `Assets/_project/Scripts`. `Bootstrap` загружает реализации `IDataCreator` и открывает главное меню. `StartMediator` и другие медиаторы управляют переходами между экранами; `View` и `Presenters` отвечают за интерфейс. `Creators` загружают справочники, `CharacterStorage` и `CharacterMapper` сохраняют состояние персонажа. Префабы находятся в `Assets/_project/Prefabs`, а сцена — в `Assets/Scenes/GameScene.unity`.
